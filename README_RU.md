# PS2 GAME STATION

Первый технический прототип для PlayStation 2 / Free McBoot.

## Что умеет эта сборка
- Запускается как самостоятельный ELF.
- Показывает стартовый экран.
- По нажатию CROSS пытается запустить OPL с USB по точному пути `mass:/OPNPS2LD.ELF`.

## Важно
Это пока не финальная оболочка библиотеки PS1/PS2: здесь ещё нет сканирования игр, обложек и запуска POPStarter. Мы сначала проверяем облачную сборку ELF и базовый запуск OPL. Внутренний HDD не форматируется и не изменяется.

## Сборка
Сборка выполняется в GitHub Actions с официальным контейнером PS2DEV. Результат публикуется как workflow artifact.
